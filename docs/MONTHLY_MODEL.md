# Месячная модель и способы вычисления достижимости

Дата: 2026-11-09.

Статус: математическое предложение по запросу автора. Направление связей
из предыдущего обсуждения одобрено; конкретные уравнения, порядок событий,
семейства функций и алгоритм ниже предложены для обсуждения. По следующему
запросу автора реализован ограниченный базовый вариант — см. раздел 11
и [отчёт запуска](reports/BASELINE_DEMO.md). Полная постановка пока
не реализована. Требования находятся в [CONCEPT.md](CONCEPT.md).

## 1. Основная конструкция

Использовать дискретное управление с неизвестными, но ограниченными
функциями отклика. На 36 месяцев записывается одна задача оптимизации
со связанными состояниями всех месяцев. Это сохраняет исследование
семейства траекторий; отдельные прогнозы могут быть свидетельствами,
но не заменяют всё семейство.

Слои модели:

1. Балансы клиентов и денег: тождества после выбора порядка событий.
2. Резерв, расходы, мощности: ограничения принятой бизнес-постановки.
3. Отклики на цену, рекламу, продукт и нагрузку: класс неизвестных функций.
4. Вычисление: допустимые свидетельства и внешние оценки возможностей.

## 2. Состояния и решения

В начале месяца t, t = 1,...,T, T = 36 в рабочем примере:

\[
x_t=(N_t,B_t,Q_t,K_t,p_{t-1},Z_t).
\]

| Величина | Смысл |
| --- | --- |
| N_t | Клиенты, которые могут продлить подписку в этом месяце |
| B_t | Денежный остаток |
| Q_t | Состояние продукта, в первой версии — один нормированный показатель |
| K_t | Мощность обслуживания при штатном качестве |
| p_{t-1} | Предыдущая цена, необходимая для реакции на её изменение |
| Z_t | Очереди ещё не завершённых улучшений и расширений |

Решения:

\[
u_t=(p_t,M_t,V_t,H_t),
\]

где p — цена для всех, M — рекламные расходы, V — расходы на улучшения,
H — расходы на расширение мощности. Зарплаты уже работающей команды
относятся к обязательным расходам, а не исчезают при H = 0.

Области: N, Q, M, V, H, p неотрицательны, K >= K_min > 0,
B >= B_min >= 0. Если используется износ продукта, 0 <= delta_Q <= 1.
Границы цены и остальных откликов рассматриваются в разделе 5.

Цена выбирается свободно от месяца к месяцу: ограничения скорости её
изменения не вводятся. Постоянство цены внутри месяца — предлагаемое
соглашение дискретной модели. Оно не охватывает автоматически все планы
с несколькими изменениями цены в месяц; вывод о невозможности для них
потребует дополнительного обоснования или внешней релаксации.

Одномерный Q — упрощение, а не доказанная достаточная характеристика
продукта. Если одинаковое Q скрывает существенно разные отклики,
понадобится несколько компонент. Аналогично K может быть заменена
отдельными мощностями инфраструктуры и поддержки.

Число клиентов в первом приближении допускается вещественным как
агрегированный объём. Это не математическое ожидание без вероятностной
модели. При малых количествах нужны целые потоки; вещественная релаксация
может использоваться только для внешней оценки целочисленной модели.

## 3. Порядок месяца и денежный резерв

Предлагается следующий явный порядок, который ещё нужно принять:

1. Выбираются решения, оплачиваются обязательные расходы и новые вложения.
2. Старые клиенты принимают решение о продлении по новой цене.
3. Продлившие оплачивают месяц; оплачивается обслуживание.
4. Приобретённые за месяц новые клиенты входят в базу следующего месяца.

Последнее — соглашение о месячном сдвиге привлечения, не универсальное
свойство подписки. Если новые клиенты платят сразу, потребуется другая
формула выручки; допустимые гарантии относятся к выбранному порядку.

Пусть d_t — доля не оплативших из начальной базы, A_t — новые клиенты
платного тарифа, привлечённые к следующему месяцу, n_t — оплатившие
текущий месяц. Тогда

\[
0\le d_t\le1,\qquad n_t=(1-d_t)N_t,\qquad
N_{t+1}=n_t+A_t,\qquad R_t=p_t n_t.
\]

Для клиентов из A_t следующий месяц содержит первую оплату, для остальных
— продление. Единая доля d предполагает одинаковый отклик этих групп;
при существенном различии вводятся две группы. CAC нужно считать по
фактически впервые оплатившим с согласованным окном атрибуции. M_t/A_t
в этом порядке событий — стоимость привлечённого клиента до первой
оплаты, которая не обязательно равна CAC платящего клиента.

Возвраты ушедших при необходимости входят в A отдельно с исключением
двойного счёта. Бесплатный доступ при явном моделировании требует своей
базы, расходов и перехода в платную. Его можно свернуть в A только вместе
с задержкой перехода и расходами на не ставших плательщиками пользователей.

Обозначим F(K_t) обязательные расходы, C(n_t,K_t) обслуживание, а

\[
E_t=F(K_t)+M_t+V_t+H_t.
\]

Если все указанные расходы признаются сразу и все поступления/выплаты
происходят в том же периоде, рабочая операционная прибыль до налогов равна

\[
P_t=R_t-E_t-C(n_t,K_t),\qquad B_{t+1}=B_t+P_t.
\]

Это отдельное упрощение учёта. При капитализации разработки, покупке
активов, налогах, дебиторской задолженности и других расхождениях прибыль
и денежный поток вычисляются отдельно; баланс B использует только деньги.
Называть такую упрощённую P чистой бухгалтерской прибылью нельзя.

При предложенном порядке и неотрицательных ценах и расходах достаточно
проверить две потенциально минимальные точки денежного остатка:

\[
B_t-E_t\ge B_{\min},\qquad B_{t+1}\ge B_{\min}.
\]

Первая проверка не позволяет платить сегодняшние зарплаты будущими
поступлениями. Этот порядок может быть консервативнее фактических
распределённых платежей. Для переноса вывода о невозможности на другой
порядок требуется внешняя оценка соответствующей модели, а не только
невозможность в предложенном порядке.

## 4. Неизвестные функции и их совместимость

Условная запись откликов:

\[
\begin{aligned}
A_t&=a_\theta(p_t,M_t,Q_t,S_t,w_t),\\
d_t&=d_\theta(p_t,\Delta p_t,Q_t,N_t/K_t,w_t),\\
Q_{t+1}&=(1-\delta_Q)Q_t+g_\theta(V_{t-\ell_Q}),\\
K_{t+1}&=K_t+k_\theta(H_{t-\ell_K}).
\end{aligned}
\]

K_t > 0. S — необязательная память рекламы/охвата, добавляемая в состояние,
если отклик зависит от истории. w — явно ограниченные внешние изменения.
При отсутствии таких изменений w и S не нужны. Индексы вложений до старта
задаются начальными очередями Z, а не выбираются бесплатно решателем.
При ell = 0 новое качество или мощность доступны с начала следующего
месяца; большая задержка реализуется сдвигом очереди.

Для отсутствия бесплатного расширения и улучшения задаются g(0) = k(0) = 0,
0 <= g(V) <= L_V V и 0 <= k(H) <= L_H H с конечными обоснованными
коэффициентами. Ненулевой нижний гарантированный эффект не предполагается
без основания. Если один и тот же ресурс нужен и продукту, и расширению,
его общая граница также должна ограничивать V и H совместно.

Эти формулы предлагают минимальную структуру; общий износ Q,
невозможность сокращения K и единый способ роста мощности ещё не являются
утверждёнными свойствами бизнеса. F(K) связывает расширение с последующими
регулярными расходами. Уже оплаченная командой разработка не должна
повторно целиком входить в V; бюджетная классификация исключает двойной счёт.

Все функции входят в один совместный класс моделей Theta. Неизвестная
модель theta выбирается один раз на горизонт; она не меняется каждый
месяц ради удобного результата. Если допустим дрейф, задаются его границы
и память. Независимое включение в интервалы каждого месячного A и d —
внешняя релаксация, а не доказательство существования одной общей модели.

Предлагаемые ограничения на форму в области применимости, при прочих равных:

- a не убывает по M и Q, не возрастает по p;
- a вогнута по M при фиксированных остальных аргументах;
- d не убывает по цене, величине её повышения и нагрузке, не возрастает по Q;
- чувствительности всех откликов ограничены;
- улучшения и расширения требуют ресурсов, эффект ограничен и задержан;
- перегрузка N/K повышает расходы и/или отток согласно выбранным границам;
- F имеет положительный обязательный минимум, расширение может увеличивать
  её ступенчато.

При дифференцируемости, например,

\[
0\le\partial_M a\le L_M,\qquad \partial^2_{MM}a\le0,
\qquad -L_p\le\partial_p a\le0.
\]

Без дифференцируемости используются конечные разности и ограничения
Липшица. Это гипотезы класса моделей, не бухгалтерские тождества.
Вогнутость по одному аргументу не означает совместной выпуклости задачи.

Насыщение рекламной отдачи и ухудшение привлечения со временем различны.
Первое задаётся вогнутостью по M; второе требует S или ограниченного
дрейфа. Снижение чистого прироста может возникнуть и без обоих механизмов:
при постоянных A и d имеем N_next - N = A - d N.

Для чисто платного привлечения a(p,0,Q,...) = 0. Органический поток,
если он допускается, выделяется и ограничивается отдельно. Нельзя оставлять
неограниченный бесплатный источник клиентов.

Совместные ограничения привлечения, оттока и стоимости должны отражать
общие условия и известные связи. Само наличие общего theta не обосновывает
неизвестный численный компромисс между откликами: без данных или гипотезы
такое ограничение нельзя придумывать ради исключения удобного сочетания.

## 5. Какая количественная информация необходима

Одной монотонности недостаточно. Для конечного полезного ответа нужны:

- начальные N_1, B_1, Q_1, K_1, цена и очереди; резерв B_min;
- обязательные расходы и допустимые границы стоимости обслуживания;
- хотя бы интервальные опорные значения привлечения и оттока;
- границы изменения откликов, эффективности вложений и задержек;
- область применимости цены и качества либо ограничения поведения
  откликов за её пределами, обеспечивающие ограниченность выручки;
- размер целевой годовой прибыли G.

Не требуется знать точную будущую кривую. Например, интервалы текущего
привлечения, оттока и допустимых чувствительностей уже сужают семейство.
Это входные данные, а не числа, выбираемые ради желаемого вывода.

Если цена не ограничена и модель допускает сохранение положительного
числа плательщиков при любой цене, прибыль может быть неограниченной.
Ограничение чувствительности само по себе этого не исключает. Аналогично
вогнутость рекламы не ограничивает её общий масштаб без опорных значений
или верхних границ отклика.

Для вычислительных релаксаций нужны конечные границы переменных. Часть
можно вывести из денег и откликов на конечном горизонте, не вводя потолок
рынка. Ограничение цены выбранным диапазоном даёт результат только для
этого диапазона; для глобальной недостижимости нельзя молча исключить
неисследованные цены.

## 6. Две задачи достижимости

Рабочее предложение для годовой цели — фактическая сумма прибыли третьего
года, а не умножение последнего месяца на 12:

\[
J=\sum_{t=25}^{36}P_t,\qquad J\ge G.
\]

Такое окно измерения и определение P требуют явного принятия как части
математической модели. Проверка резерва действует во всех 36 месяцах.
Годовой темп на конец срока и устойчивая прибыль после срока — другие цели.

Обозначим xi = (theta,w_1,...,w_T) из совместного допустимого множества Xi.
До проверки цели нужно проверить совместимость ограничений откликов
и начальных данных и убедиться, что Xi непусто. Противоречивые сведения
о бизнесе означают несогласованную модель, а не содержательное доказательство
невозможности бизнеса. При пустом Xi робастная формула была бы истинна
вакуозно, что не является гарантией.

**Совместимость с целью:**

\[
\exists\xi\in\Xi\ \exists u_{1:T}:\quad
\text{выполнены все балансы и ограничения},\quad J\ge G.
\]

Оптимистический предел V_poss — супремум J по этим xi и управлениям.
Один конкретный допустимый xi и план с J >= G свидетельствуют о возможности
в рамках модели. Значение супремума без найденного допустимого плана
не заменяет такого свидетельства.

**Робастная гарантия:**

\[
\exists\pi\ \forall\xi\in\Xi:\quad
u_t=\pi_t(\mathcal I_t),\quad
\text{все ограничения выполнены},\quad J\ge G.
\]

I_t содержит только уже доступные наблюдения, решения и сведения о
совместимых моделях. Нельзя выдавать разные решения для неразличимых
на этот момент историй. Неизвестное истинное theta не наблюдается напрямую.

Информация о постоянной неизвестной модели обновляется наблюдениями.
При измерительных ошибках оставляются все совместимые с их границами
модели. Для динамического программирования требуется состояние информации
(в том числе множество совместимых theta и скрытых состояний), иначе
помесячный выбор нового худшего theta решает иную, обычно более жёсткую
задачу. Без доказанного упрощения состояния обычный минимакс по x неверен.

Фиксированный план, работающий для всех xi, — достаточная робастная
стратегия. Отсутствие такого плана не исключает адаптивную стратегию.

## 7. Конечное представление неизвестных функций

Практическое предложение — узлы и интервалы значений вместо единственной
угаданной экспоненты. Например, для фиксированных p, Q и прочих аргументов
в узлах рекламного бюджета m_j:

\[
\underline a_j\le a_j\le\overline a_j,\qquad
0\le\frac{a_{j+1}-a_j}{m_{j+1}-m_j}
\le\frac{a_j-a_{j-1}}{m_j-m_{j-1}}\le L_M.
\]

Так задаются семейства возрастающих вогнутых рекламных откликов. Узловые
значения — общие неизвестные на все месяцы. По цене и качеству добавляются
обоснованные ограничения формы и совместимости.

Кусочно-линейная интерполяция определяет конкретный подкласс функций.
Она не охватывает автоматически все исходные допустимые функции.
Для внешней оценки нужно дополнительно учитывать ошибку между узлами.
Например, при известной константе Липшица L и расстоянии до используемых
узлов не более delta допустима граница ошибки L delta для интерполяции
выпуклой комбинацией их значений. Нормы и единицы должны быть согласованы.

Линейные ограничения формы на узлы не делают всю задачу линейной:
неизвестные значения функций могут умножаться на переменные веса
интерполяции. Достаточность узловых условий для существования глобальной
функции с нужной формой нужно проверять. Без неё решение релаксации
остаётся только внешней оценкой.

## 8. Как считать практически

### 8.1. Записать весь горизонт одновременно

Использовать прямую запись уравнений всех месяцев как ограничений
конечной оптимизационной задачи. Сетку по всему многомерному состоянию
на первом шаге не строить. При фиксированных размерностях состояний
и очередей число временных переменных растёт линейно с T; сложность
решения от этого не становится линейной.

Основные нелинейности: p_t n_t, d_t N_t, отклики и их интерполяция.
Ступени найма и расходы включения можно представить целочисленными
переменными. Для ограниченных переменных используются линейные внешние
релаксации произведений, кусочно-линейные границы и ветвление с уточнением.
Обычный локальный поиск полезен для кандидатов, но не даёт верхней границы
максимальной прибыли.

Например, для z = xy при x в [l_x,u_x], y в [l_y,u_y] внешняя оболочка:

\[
\begin{aligned}
z&\ge l_xy+l_yx-l_xl_y,\\
z&\ge u_xy+u_yx-u_xu_y,\\
z&\le u_xy+l_yx-u_xl_y,\\
z&\le l_xy+u_yx-l_xu_y.
\end{aligned}
\]

Она содержит все точные произведения в прямоугольнике, но также лишние
точки. Например, первая нижняя граница следует из
(x-l_x)(y-l_y) >= 0; остальные следуют из произведений соответствующих
неотрицательных расстояний до сторон прямоугольника.
Разбиение прямоугольников уточняет оценку. Фиксированная сетка цен
сужает допустимые решения, поэтому её неудача не доказывает невозможность
при непрерывном изменении цены.

### 8.2. Держать раздельно два вида свидетельств

\[
L_{poss}\le V_{poss}\le U_{poss}.
\]

L_poss получается из траектории, проверенной вместе с одной общей
допустимой моделью откликов. U_poss — из внешней релаксации, которая
доказанно содержит все исходные допустимые траектории.

- U_poss < G: цель условно недостижима, в том числе робастно.
- Проверенный план с J >= G: цель совместима с ограничениями.
- L_poss < G <= U_poss: вычисление пока не решило вопрос.

Зазор U_poss - L_poss — вычислительная неопределённость оптимистической
задачи. Он не равен разнице между благоприятным и робастным исходами.

Число из решения релаксации не является готовым бизнес-планом.
Проверка кандидата включает исходные произведения, баланс каждого этапа
месяца, общую функцию отклика, задержки и целевое окно.

### 8.3. Робастность — отдельный следующий уровень

Для выбранного плана или класса причинных политик:

1. Найти кандидат по текущему набору допустимых моделей.
2. Искать по всему Xi худшее нарушение резерва/ограничений и худшую прибыль.
3. Добавлять найденные контрпримеры и пересчитывать решения.
4. Объявлять гарантию только при сертифицированной границе худшего случая.

Сценарии должны сохранять одно theta на горизонт и неупреждаемость
решений. Проверка конечного набора сценариев сама по себе не гарантирует
работу на всём Xi. Неудача ограниченного класса политик не доказывает
отсутствие любой робастной стратегии.

Чередование оптимизации и поиска худшего случая известно в робастной
оптимизации. Результаты сходимости для выпуклой задачи с точным поиском
худшего случая не переносятся автоматически на эту нелинейную модель.

### 8.4. Погрешности и статус вывода

Границы решателя должны учитывать погрешности аппроксимации и вычислений.
Статус «не найдено решение» или остановка по времени не являются
свидетельством несовместности. Для строгого доказательства требуется
независимо проверяемая верхняя граница или сертификат несовместности
с контролем численных ошибок; обычный расчёт в плавающей точке следует
называть численным свидетельством с указанными допусками.

Полезные статусы отчёта: условно невозможно; есть допустимый успешный
пример; есть проверенная робастная стратегия; вопрос пока не разрешён.
К каждому прикладываются исходные ограничения и погрешности.

## 9. Минимальный капитал как дополнительная задача

После фиксации цели можно минимизировать начальный B_1 при неизменных
остальных начальных условиях. Это не дополнительное финансирование:
деньги доступны только до старта. Оптимистический и робастный минимумы
капитала — разные величины.

Для фиксированной траектории расходов и поступлений, не зависящей от
начального остатка, обозначим S_0 = 0, S_t = sum_{s=1}^t P_s. Тогда при
порядке из раздела 3 необходимый и достаточный начальный капитал равен

\[
B_{1,min}=B_{min}+\max\left\{0,
\max_{1\le t\le T}(E_t-S_{t-1}),
\max_{1\le t\le T}(-S_t)\right\}.
\]

Формула следует из двух денежных неравенств каждого месяца. Она относится
к фиксированному плану и принятому совпадению прибыли с денежным потоком,
а не решает оптимизацию по всем стратегиям. В общем учёте вместо P
используется чистый денежный поток.

## 10. Предлагаемая последовательность дальнейшей работы

1. Принять порядок месяца, окно годовой прибыли и определение прибыли.
2. Задать символические входные интервалы, затем отдельный условный набор
   чисел с явной пометкой, что это не данные стартапа.
3. Получить простую внешнюю оценку оптимистического результата и проверенный
   допустимый план; уточнять только существенные для зазора ограничения.
4. Отдельно исследовать минимум начального капитала и ограничения,
   определяющие недостижимость.
5. Перейти к проверке фиксированных планов на всём Xi, затем к адаптивным
   стратегиям, если это необходимо для содержательного результата.

Для полной постановки выбор библиотек, решателя и чисел пока не завершён.
Фактически выбранные средства ограниченного прототипа описаны в разделе 11.
Обещать время расчёта до выбора класса функций и размеров сеток нельзя.

### 11.1. Фиксированные допущения

- Состояния — клиентская база N и деньги B. Продукт, команда и мощность K
  постоянны; улучшения V и расширение H в этой версии отсутствуют.
- Решения — цена p и рекламные расходы M. В расчёте планов используются
  конечные наборы `prices` и `marketing_budgets`; симулятор принимает
  произвольные положительные цены и неотрицательные бюджеты.
- Цена в течение месяца постоянна, меняется для всех. Отдельного эффекта
  скачка цены и памяти предыдущих тарифов пока нет.
- Годовая цель — сумма прибыли последних `profit_window_months`
  (в примере 12) месяцев, горизонт `months` (в примере 36).
- Прибыль операционная до налогов; все расходы признаются и оплачиваются
  в текущем месяце. Поэтому разность денежных остатков совпадает с прибылью.
- В начале месяца оплачиваются F + M, затем оставшиеся клиенты платят
  по новой цене, затем оплачивается их обслуживание c*n. Новые клиенты A
  входят в базу следующего месяца; CAC впервые оплатившего не отождествляется
  с M/A автоматически.
- Резерв проверяется после F + M и в конце месяца. Дополнительного
  финансирования нет. При нарушении расчёт останавливается с причиной
  и месяцем, будущая выручка не используется для покрытия нарушения.
- Платящая база n <= K: мощность здесь является жёстким ограничением,
  без модели перегрузки и частичного отказа. Клиенты и потоки вещественные.

### 11.2. Конечное семейство откликов

Для каждой перечисленной в JSON модели задаются постоянные на горизонте
коэффициенты k, d_0, e_a, e_d. Общими являются опорная цена p_0 и масштаб S:

\[
A(p,M)=kS\log(1+M/S)(p_0/p)^{e_a},\qquad
d(p)=\min\{1,d_0(p/p_0)^{e_d}\}.
\]

k >= 0, S > 0, p > 0, 0 <= d_0 <= 1, e_a,e_d >= 0.
Отклик рекламы возрастает и вогнут по M, A(p,0) = 0, верхнего
предела числа привлечений при неограниченном M сама формула не вводит.
Цена снижает привлечение и повышает долю ухода. Это выбранное семейство
гипотез, а не оценка реального рынка. Параметр k не равен обратному
постоянному CAC: стоимость привлечения меняется с p и M.

Каждая модель остаётся одной и той же все месяцы. По умолчанию ищется
единый фиксированный план для всех перечисленных моделей, максимизирующий
минимальную из их годовых прибылей. При `--scenario` набор можно сузить.
Ни вероятности моделей, ни вероятности успеха не назначаются.

### 11.3. Точная MILP-запись ограниченного поиска

На фиксированной сетке для каждого действия j известны A_sj и r_sj = 1-d_sj
в каждой модели s. Вводятся бинарные y_tj с суммой 1 и неотрицательные
w_stj, такие что

\[
\sum_j w_{stj}=N_{st},\qquad 0\le w_{stj}\le U_{st}y_{tj}.
\]

При бинарных y ненулевое w равно N в выбранном действии. Можно взять
конечную границу U_st = N_0 + t max_j A_sj, поскольку сохранение клиентов
не превосходит 1. Тогда переходы линейны:

\[
\begin{aligned}
N_{s,t+1}&=\sum_j r_{sj}w_{stj}+\sum_j A_{sj}y_{tj},\\
B_{s,t+1}&=B_{st}+\sum_j(p_j-c)r_{sj}w_{stj}-F-\sum_j M_jy_{tj}.
\end{aligned}
\]

Дополняются проверками предоплаты, конечного резерва, мощности и
z <= B_s,T - B_s,T-W для каждой модели s. Максимизируется z.
Внутри этой конечной задачи линейная запись произведений точна;
это не внешняя оценка непрерывного управления или общего класса функций.

Используется `scipy.optimize.milp` / HiGHS. Денежные переменные решателя
выражены в тысячах денежных единиц. Полученный дискретный план заново
считается независимым симулятором в исходных единицах. Денежный допуск
проверки — 0,01, допуск мощности — 1e-7 клиента.

### 11.4. Статусы и артефакты

Отчёт содержит исходную конфигурацию, прибыль проверенного плана,
численную верхнюю границу maximin-оптимума единого фиксированного плана
на сетке, зазор и статус поиска. Эта граница не ограничивает сверху
каждую отдельную благоприятную траекторию и не является верхней оценкой
оптимистической задачи из раздела 6.
Остановка без плана не объявляется невозможностью. Недопустимый кандидат
не используется как успешный результат. Формальной проверки сертификатов
с точной арифметикой пока нет.

Экспортируются JSON отчёта и плана, CSV траекторий. Отдельная команда
перебирает все постоянные действия из той же сетки; это сравнение с
ограниченным классом решений, а не со всеми альтернативными методами.
Минимальный капитал в отчёте относится только к найденному фиксированному
плану, не является глобальным минимумом по стратегиям и включает резерв.

Первые результаты и содержательные ограничения разобраны в
[BASELINE_DEMO.md](reports/BASELINE_DEMO.md). Основные открытые вопросы —
обоснованность откликов, реакция на повышение цены, эффект конца горизонта
и добавление наблюдаемой информации о скрытых состояниях.

Сравнение с литературой, исследовательский эксперимент и предлагаемые
следующие этапы находятся в [RESEARCH_NOTES.md](RESEARCH_NOTES.md#сравнение-с-литературой-и-аналогами--2026-11-09)
и [IMPROVEMENT_PLAN.md](IMPROVEMENT_PLAN.md). Изолированное сравнение
удержания не заменяет проверку прогнозов прибыли и политик управления.
